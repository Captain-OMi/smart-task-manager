6. API Endpoints Reference

Authentication

  • POST /register
  • POST /login
  • GET /logout

Task Operations

  • GET /tasks
  • POST /task/add
  • PUT /task/update
  • DELETE /task/delete

Admin Controls

  • GET /users
  • DELETE /user/delete
  • DELETE /admin/task/delete
